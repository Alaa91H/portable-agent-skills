# Arabic news briefing

A briefing is read on a phone, by someone scanning forty headlines. It is not an
essay and not a wall of text. Each item must stand alone and be skimmable in ten
seconds.

## Shape of one item

```
**Headline that says what happened** — date — confidence

• **ما حدث:** the fact, in one or two sentences.
• **التفاصيل:** the numbers, names, versions — only what the source states.
• **السياق:** why it matters to this reader.
• **تحليل:** your read, clearly separated from the facts above.
• **الرابط:** the source URL.
```

Rules that make it readable:

- One field per line, never a paragraph with fields glued together by `·`.
- The headline is a sentence, not a topic label.
- Facts and analysis are never mixed inside the same field.
- If the item has no image, say nothing about images. Never write "لا توجد صورة".

## A briefing is a list

- Lead with an executive summary of numbered one-liners, then the items.
- Group items under section headings only when the grouping is real.
- Items per briefing: say the number up front, and deliver exactly that number.

## Honesty rules

- Never invent a URL, a number, a date, a version, or a company name.
- Never let a fragment of a tool name, a path, or a foreign word slip into the
  text. If you cannot phrase it cleanly, leave it out.
- Mixed scripts inside an Arabic sentence are a defect. If a term only exists in
  Latin, write it in Latin deliberately and keep it out of the Arabic sentence.
- If a source could not be opened, say so on that item instead of summarising it
  from the headline.

## Before you finish

1. Count the items: it must match the count you promised.
2. Scan for the same phrase twice in a row — if it appears, you are looping, and
   the remaining text must be cut.
3. Confirm every link you kept is one you actually opened.
